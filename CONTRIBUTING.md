# Contribuer au projet

Merci de vouloir contribuer à MaisonConnect.

## Règles de contribution

1. Créer une issue avant de commencer une modification.
2. Créer une branche adaptée :
   - `feature/nom-fonctionnalite`
   - `fix/nom-correction`
   - `hotfix/nom-correction-urgente`
3. Faire des commits signés.
4. Ouvrir une pull request vers `develop`.
5. Vérifier que le linter passe avec :

```bash
npm run lint
