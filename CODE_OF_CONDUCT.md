# Code de conduite

Ce projet doit rester un espace respectueux et bienveillant.

## Nos engagements

Les contributeurs s'engagent à :

- respecter les autres membres du projet ;
- accepter les retours constructifs ;
- communiquer clairement ;
- éviter les propos insultants, discriminatoires ou agressifs.

## Comportements non acceptés

- insultes ;
- harcèlement ;
- discrimination ;
- sabotage volontaire du projet.

## Application

En cas de problème, les membres du groupe doivent en discuter calmement et prévenir l'encadrant si nécessaire.
