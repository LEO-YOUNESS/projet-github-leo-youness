# Code de conduite

Ce projet doit rester un espace de travail respectueux et bienveillant entre les membres du groupe.

## Nos engagements

En tant que contributeurs de ce projet, nous nous engageons à :

- respecter les autres membres du projet ;
- accepter les retours constructifs avec ouverture ;
- communiquer clairement, notamment dans les issues et les pull requests ;
- éviter les propos insultants, discriminatoires ou agressifs.

## Comportements non acceptés

- insultes ou attaques personnelles ;
- harcèlement sous toutes ses formes ;
- discrimination, quelle qu'en soit la nature ;
- sabotage volontaire du travail d'un membre du projet (suppression de code, force push destructif, etc.).

## Application

En cas de désaccord ou de comportement problématique, les membres du groupe doivent d'abord en discuter calmement entre eux. Si le problème persiste, l'encadrant du projet doit être prévenu.
